# Security policy

If you discover a security vulnerability in this project, please report it by opening a GitHub issue with the label "security" or by contacting the repository owner directly.

Guidance for reporters:
- Provide steps to reproduce and any relevant PoC (proof-of-concept) code.
- If the vulnerability exposes credentials, rotation instructions should be included.

Notes for maintainers:
- This repository includes demo credentials for local testing. Do not use demo credentials in production.
- Enable GitHub Secret Scanning and Dependabot Alerts for automated detection of issues.
